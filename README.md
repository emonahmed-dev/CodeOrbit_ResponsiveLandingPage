
# Nexora — Responsive Landing Page

A modern and responsive landing page for a fictional digital agency called **Nexora**.

This project was created as part of my frontend development internship at CodeOrbit Tech. The main goal of this project was to practice and strengthen my fundamentals of HTML, CSS, JavaScript, responsive web design, and UI development.


## 🚀 Live Demo

https://nexora-responsive-landing-page.netlify.app/


## 📸 Preview

![Nexora Landing Page Preview](https://i.ibb.co.com/pvzX618z/screencapture-nexora-responsive-landing-page-netlify-app-2026-09-04-10-56-31.png)


## ✨ Features

- Fully responsive design
- Responsive navigation bar
- Mobile hamburger menu
- Smooth mobile menu animation
- Hero section with call-to-action buttons
- Company statistics section
- Services section
- About / Why Choose Us section
- Recent projects / portfolio section
- Call-to-action section
- Responsive footer
- Font Awesome icons
- Mobile, tablet, and desktop layouts


## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Font Awesome
